# WritingLab 1.7.6

## 中文

- 项目根文档的 YAML 项目头缺失时，如果同目录仍保留多个 NarrativeLab 专属的 `System` 数据标记，且根文档不存在歧义，项目扫描器会恢复识别。扫描只读取现有内容，不会改写正文。
- 文件列表中的“眼睛”现在只会在已识别的 NarrativeLab 项目范围内隐藏 Obsidian 无法打开的内部文件。项目外的 XLSX 等文件保持可见。
- 新增缺失项目头恢复与项目范围文件隐藏的回归测试。

## English

- Project discovery can recover an unambiguous root document whose project YAML header is missing when multiple NarrativeLab-owned `System` markers remain. Scanning reads the existing content without rewriting the document body.
- The Files-view eye control now hides unsupported internal files only inside registered NarrativeLab projects. XLSX and other unsupported files elsewhere in the vault remain visible.
- Added regression coverage for guarded project recovery and project-scoped file visibility.

## Installation

Replace `main.js`, `manifest.json`, and `styles.css` in the existing `narrative-lab` plugin directory with the release assets, then reload the plugin or restart the application. Keep your existing `data.json`, writing-tracker records, and project files.

Minimum supported application version: 1.12.7.
