# WritingLab 1.7.7

## 中文

- 系列扫描改用 Obsidian 文件索引。系列放在用户自行创建的 `Archived`、`Notes`、`Library` 等目录下时仍可正常识别。
- 当 `series.json` 的项目顺序清单落后于实际目录时，项目管理会补充显示同一系列目录下已识别的项目。扫描过程不会改写项目正文或系列元数据。
- 文件列表隐藏规则现已覆盖受管理系列的 `series.json.bak` 与 `series.json.tmp`，其他目录中的同名备份文件不受影响。

## English

- Series discovery now uses the Obsidian file index, keeping valid series discoverable below user-created folders such as `Archived`, `Notes`, and `Library`.
- When the project order in `series.json` is stale, project management supplements it with recognized direct-child projects in the same series folder. Discovery does not rewrite project documents or series metadata.
- File Explorer hiding now covers managed `series.json.bak` and `series.json.tmp` files without affecting similarly named backups elsewhere.

## Installation

Replace `main.js`, `manifest.json`, and `styles.css` in the existing `narrative-lab` plugin directory with the release assets, then reload the plugin or restart the application. Keep your existing `data.json`, writing-tracker records, and project files.

Minimum supported application version: 1.12.7.
