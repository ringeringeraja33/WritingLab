# WritingLab 1.7.1

## 中文

- 资料库模式改为严格互斥的文献、叙事、混合与空资料库策略。文献项目不再生成角色、地点、叙事场景或叙事 Canvas，平铺画布的内部文件也不再占用用户的 Canvas 文件夹。
- 资料图谱关系词汇按项目隔离。学术资料库默认只使用引用、支持、反驳，同时保留用户自定义的学术关系，不再混入技能等叙事关系。
- 资料图谱的关系元数据更新限制在当前项目范围；项目重命名或删除时同步迁移、清理项目级界面、图谱与画布状态，避免旧配置回流。
- 修正项目页签拖动后回弹的问题，排序改为指针拖动并串行保存。
- 统一平铺画布与表格的两层顶栏、图标尺寸和对齐方式；所有 WritingLab 页面均隐藏重复的 Obsidian 原生标题栏及 Commander 按钮区。
- 原生 Obsidian Base 按钮不再为浏览型学术分类单独占据一行，而是并入资料库分类栏。
- “节点式演示画布”统一简称为“演示”。
- 统一项目、全库和文件夹写作统计的正文提取与分词规则；排除 frontmatter 和嵌入图片，并修正快速保存、短中文文本及异步汇总导致的漏记或重复计数。
- 加强项目能力切换、文件夹创建、删除失败回滚和跨项目缓存隔离，避免被禁用模块从其他入口重新生成数据。

## English

- Library packs now use one canonical, mutually exclusive policy: academic, narrative, combined, or empty. Academic projects no longer create character, location, narrative-scene, or authored Canvas storage, and flat-board backing files stay internal.
- Story Graph relation vocabularies are isolated per project. Academic libraries keep cites, supports, refutes, and user-defined academic relations without inheriting narrative relation types.
- Story Graph metadata updates are scoped to the current project. Project rename and deletion also migrate or remove project-owned UI, graph, and canvas state so stale settings cannot return.
- Project tabs now use serialized pointer-based reordering, preventing drag-and-drop rebound.
- Flat Canvas and Table share a consistent two-row header, icon geometry, spacing, and alignment. Every WritingLab view hides the redundant native Obsidian header and Commander action row.
- Browse-only academic categories place the native Obsidian Base action in the Library category row instead of creating an otherwise empty toolbar.
- “Node-based presentation canvas” is now shown simply as “Presentation.”
- Project, vault, and folder writing statistics now share body extraction and tokenization rules. Frontmatter and embedded images are excluded, with fixes for rapid saves, short CJK text, and asynchronous ledger reconciliation.
- Capability changes, folder creation, deletion rollback, and cross-project caches are hardened so disabled modules cannot recreate storage through secondary entry points.

## Installation

Update through the community plugin updater, or replace `main.js`, `manifest.json`, and `styles.css` in the existing `narrative-lab` plugin directory with the release assets. Restart Obsidian or reload the plugin afterward. Keep your existing `data.json` and project files.

Minimum supported Obsidian version: 1.12.7.
