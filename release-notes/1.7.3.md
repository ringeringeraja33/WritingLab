# WritingLab 1.7.3

## 中文

- 将表格从“整理”下拉菜单中移出，在“文稿”后新增独立的“信息表”页签。
- “信息表”点击后直接打开表格，不再显示没有必要的下拉箭头；项目模块与页签布局中的名称同步更新。
- 保留原有表格文件、工作表内容和项目模块设置，不迁移或改写用户数据。

## English

- Moved the spreadsheet out of the Organize menu into a dedicated Information table tab immediately after Manuscript.
- The Information table opens directly without an unnecessary dropdown chevron. Project module and tab-layout labels now use the same name.
- Existing workbook files, worksheet contents, and project module settings remain unchanged; no user data is migrated or rewritten.

## Installation

Replace `main.js`, `manifest.json`, and `styles.css` in the existing `narrative-lab` plugin directory with the release assets, then reload the plugin or restart the application. Keep your existing `data.json`, writing-tracker records, and project files.

Minimum supported application version: 1.12.7.
