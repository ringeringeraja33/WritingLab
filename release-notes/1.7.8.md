# WritingLab 1.7.8

## 中文

- 每个项目的文稿 Base、资料库 Base 和表格都保存在该项目自己的 `Library/` 中，加入系列后也是如此。系列 `Library/` 用于共享资料。
- 旧版误放在系列 `Library/` 或 `Codex/` 中、且带有项目名的文件，会在使用对应功能时迁回所属项目。
- 项目里已经有同名文件时，两份都保留，不会覆盖。没有项目名的历史共享文件留在原处。

## English

- Document Bases, Library Bases, and spreadsheets stay in each project's own `Library/`, including series members. The series `Library/` holds shared material.
- Named legacy files left in a series `Library/` or `Codex/` move back to the owning project when that feature is used.
- If the project already has a file at the destination, both copies are kept. Unnamed shared legacy files stay where they are.

## Installation

Replace `main.js`, `manifest.json`, and `styles.css` in the existing `narrative-lab` plugin directory with the release assets, then reload the plugin or restart the application. Keep your existing `data.json`, writing-tracker records, and project files.

Minimum supported application version: 1.12.7.
