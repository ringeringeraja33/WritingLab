# WritingLab 1.7.5

## 中文

- 统一“项目设置 → 页签布局”的界面：模块分组改为一致的卡片样式，多页面分组只显示一次标题，单页面分组不再重复显示名称，并统一间距、操作控件和滚动区域。
- 启动 WritingLab 时，如果暂时没有检测到任何项目，不再自动弹出“新建项目”窗口。用户仍可从功能区按钮、命令面板或项目选择器手动创建项目。
- 新增页签布局显示与无项目启动行为的回归测试。

## English

- Unified the Project Settings → Tab layout interface with consistent framed group cards. Multi-page groups now show one heading, single-page groups avoid duplicate labels, and spacing, controls, and scrolling share one visual system.
- Starting WritingLab with no detected projects no longer opens the new-project wizard automatically. Projects can still be created manually from the ribbon, command palette, or project selector.
- Added regression coverage for tab-layout presentation and empty-project startup behavior.

## Installation

Replace `main.js`, `manifest.json`, and `styles.css` in the existing `narrative-lab` plugin directory with the release assets, then reload the plugin or restart the application. Keep your existing `data.json`, writing-tracker records, and project files.

Minimum supported application version: 1.12.7.
