# WritingLab 1.7.2

## 中文

- 修复窄分栏下项目页签与工具按钮重叠的问题。布局根据实际面板宽度调整，窄栏将项目名称与操作、页签、页面工具分行排列，按钮换行后自动增加行高。
- 窄栏中的项目设置显示为带提示的齿轮按钮，长项目名称截断显示；统计面板的按钮和长文件夹名称支持换行，避免横向溢出。
- 取消项目创建和模块启用时预建空的 `SceneNotes` 文件夹。浏览场景或保存空附注不会创建目录和文件，仅在主动写入附注或创建附注文件时按需生成；已有附注文件及其关联保持不变。
- 增加 240–900 px 面板宽度、窄侧栏和场景附注按需存储的回归测试。

## English

- Fixed overlap between project tabs and toolbar controls in narrow workspace panes. Layout follows the actual pane width, with separate rows for the project title and actions, tabs, and page controls. Wrapped controls expand their row height.
- Project settings use an accessible icon in narrow panes. Long project titles truncate, while tracker buttons and saved-folder names wrap within narrow sidebars.
- Project creation and module activation no longer pre-create an empty `SceneNotes` folder. Reading a scene or saving empty notes does not create storage. Notes files are created on demand when writing notes or explicitly creating a notes file; existing notes and links remain intact.
- Added regression coverage for 240–900 px pane resizing, narrow tracker panels, and lazy scene-note storage.

## Installation

Replace `main.js`, `manifest.json`, and `styles.css` in the existing `narrative-lab` plugin directory with the release assets, then reload the plugin or restart the application. Keep your existing `data.json`, writing-tracker records, and project files.

Minimum supported application version: 1.12.7.
