# WritingLab 1.7.4

## 中文

- 统计列表中的所有文件夹在插件运行期间持续独立记录编辑。无需在统计侧栏选中对应文件夹，关闭侧栏也不影响计数；重启后自动恢复整个列表的统计。
- 切换文件夹仅改变显示的统计数字，不重新扫描文件、不重置会话，也不停止写作冲刺。嵌套统计范围分别保存记录，同一编辑在每个匹配范围内只计一次。
- 将“停止文件夹统计”改为“移出统计列表”。移出后仅停止该范围的计数，历史保留；重新添加相同范围后继续记录。此操作不会删除源文件夹或文稿。
- 精简文件夹统计卡片，移除说明段落，保留名称、状态、字数、选择器和操作按钮；悬停提示仍可查看。
- 新增后台计数、切换显示、重启恢复、嵌套文件夹、移出与重新添加，以及异步读取竞态的回归测试。

已有或导入的内容不计为新增写作量。插件关闭期间或移出列表期间的编辑不追溯计数。会话与冲刺时长仍按对应文稿文件的打开时间计算，与统计侧栏是否显示无关。

## English

- Every folder in the tracking list records edits independently while the plugin is running. Selecting its statistics or keeping the sidebar open is no longer required. All listed scopes resume after workspace startup.
- Switching folders only changes the displayed statistics. It does not rescan files, reset a session, or stop a writing sprint. Overlapping scopes keep separate histories and count each matching edit once per scope.
- Replaced Stop folder tracking with Remove from tracking list. Removal stops only that scope and keeps its history. Re-adding the same scope resumes recording; source folders and documents are never deleted.
- Simplified the folder statistics card by removing explanatory paragraphs. Names, status, counts, selectors, action buttons, and contextual tooltips remain available.
- Added regression coverage for background counting, display switching, startup recovery, overlapping folders, removal and re-adding, and asynchronous indexing races.

Existing or imported text is not counted as new writing. Edits made while the plugin is closed or a scope is removed are not counted retroactively. Session and sprint clocks still follow open document files, independently of the statistics sidebar.

## Installation

Replace `main.js`, `manifest.json`, and `styles.css` in the existing `narrative-lab` plugin directory with the release assets, then reload the plugin or restart the application. Keep your existing `data.json`, writing-tracker records, and project files.

Minimum supported application version: 1.12.7.
